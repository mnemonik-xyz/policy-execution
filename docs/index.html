Warrant Seller MCP

An AI agent can buy one hour of a GPU running Whisper transcription, pay for it in USDC on Arc mainnet, and release the money only when it accepts the work. Warrant checks the buyer's policy and holds the funds in escrow.

Request access Read the README
Read before you try it
  • The seller endpoint is protected by basic auth. Request access; the operator sends the credential privately.
  • Deals are capped at 1 USD and one deal runs at a time.
  • The mainnet seller path (funding, acceptance, GPU provisioning, settlement) has not run with real money yet. The first paid buyer is the first test.
  • The seller's escrow uses a test-double verifier that checks no proof. A buyer trusts the seller. A signature-checking verifier is deployed but not used yet.

Try the seller

  1. Request access and wait for the credential. Never post it publicly.
  2. Make the header value in your own terminal:
    printf 'Basic %s' "$(printf '%s:%s' "<user>" "<password>" | base64 | tr -d '\n')"
  3. Add the server https://seller.mnemonik.xyz/mcp to Claude Desktop or Cursor through mcp-remote, with the header Authorization:${SELLER_AUTH}. The README has the exact configuration.
  4. Ask your agent for a quote with a maximum of 1.00 USD and give it your Arc wallet address. A quote moves no money. A one-hour RTX 4090 costs about 0.30 USD.
